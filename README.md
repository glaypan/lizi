# 声波反射与扩散模拟器

一个交互式的声学模拟可视化工具，用于演示声波在房间内的反射、漫射、驻波和3D传播效果。

## 在线预览

直接在浏览器中打开 `acoustic-reflection-simulation.html` 即可运行，无需任何构建步骤。

## 功能特性

- **反射模拟** — 观察声波从墙壁反射的路径和声压分布
- **漫射模拟** — 模拟声波遇到扩散体后的散射效果
- **驻波模拟** — 可视化房间内的驻波模式和频率响应
- **3D 总览** — 三维视角查看声源、听音点和房间布局

## 交互控制

每个模拟 Tab 均支持：

- **主音量** — 控制粒子视觉效果的总体强度（0–100）
- **全向音箱 SPL** — 调节全向声源的声压级（0–140 dB）
- **点源音箱 SPL** — 调节定向点声源的声压级（0–140 dB）
- **传播速度** — 调整声波动画速度
- **粒子密度** — 控制同时显示的粒子数量
- **暂停 / 继续** — 冻结或恢复动画

## 技术栈

- 纯原生 HTML / CSS / JavaScript（单文件，零依赖）
- Canvas 2D 粒子系统
- ECharts 数据可视化
- Apple HIG 风格设计系统

## 设计原则

- **人体工学** — WCAG AAA 对比度，舒适的阅读体验
- **苹果风格** — 简洁、克制的视觉层次
- **免费商用字体** — 使用 OFL 1.1 授权字体

## 本地运行

```bash
python3 -m http.server 8767
# 然后访问 http://localhost:8767/acoustic-reflection-simulation.html
```

或者直接双击 HTML 文件在浏览器中打开。
