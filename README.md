# 声学粒子模拟

密闭空间声波反射路径的粒子动态可视化 — 全向十六面体音箱 vs 普通点音源音箱

## 在线访问

GitHub Pages: 部署后自动生成

## 功能

- **反射路径**：1~3次反射粒子动态，SPL 图表
- **漫射扩散**：能量扩散分布，雷达图
- **驻波**：波腹/波节可视化，峰谷曲线
- **3D 模型**：三维房间粒子反射，可调尺寸/吸声系数，RT60 衰减曲线，XYZ 坐标轴

## 使用

直接用浏览器打开 `standalone.html`，或访问部署后的在线地址。

## 技术栈

- 纯 HTML/CSS/JavaScript（无框架依赖）
- ECharts 5（CDN 加载）
- Canvas 2D 渲染
